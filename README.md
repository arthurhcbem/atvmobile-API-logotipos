# atvmobile-API-logotipos
App sorteador de logotipos desenvolvido em **React Native** com **Expo** e **TypeScript**.
O app foi desenvolvido para a disciplina de coding mobile e o seu objetivo é consumir dados de uma API externa para sortear e exibir logotipos de marcas conhecidas em tempo real.
Ele consome dados da API logotypes.dev e exibe a imagem do logotipo e o nome da empresa abaixo.
